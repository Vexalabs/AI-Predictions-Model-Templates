=================================================================================

If it shows "origin", skip the next command.
If it shows nothing or different URL, run:
git remote remove origin
git remote add origin https://github.com/Vexalabs/AI-Predictions-Model-Templates.git

=================================================================================
Fetch the main branch from GitHub
=================================================================================
git fetch origin main

=================================================================================
Create a new branch from main (this will be your feature branch)
=================================================================================
git checkout -b feature/cyborgnature-snp500-predictor origin/main

If that fails, try:
git branch feature/cyborgnature-snp500-predictor
git checkout feature/cyborgnature-snp500-predictor

=================================================================================
Push your new branch to GitHub
=================================================================================
git push -u origin feature/cyborgnature-snp500-predictor
